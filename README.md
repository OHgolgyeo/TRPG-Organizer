# TRPG Organizer

TRPG 시나리오와 자료를 정리하고 Roll20 또는 CCFOLIA의 채팅 입력창으로 빠르게 전송하기 위한 프로그램입니다.


## 다운로드

### Windows
`TRPG Organizer-Setup-0.1.0.exe`

### macOS
사용 중인 Mac에 맞는 파일을 내려받아 주세요.

- Apple Silicon Mac (M1 / M2 / M3 / M4 등): `arm64`
- Intel Mac: `x64`

`.dmg` 또는 `.zip` 중 편한 형식을 사용하시면 됩니다.

## 처음 실행이 되지 않을 때

### Windows

Windows에서 처음 실행할 때
**“Windows의 PC 보호”**, **“Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 차단했습니다”**
같은 창이 나타날 수 있습니다.

이 경우:

1. `추가 정보`를 클릭합니다.
2. `실행` 버튼을 클릭합니다.

개인 배포 프로그램이라 Windows의 코드 서명이 적용되어 있지 않아 표시될 수 있는 안내입니다.

### macOS

macOS에서 처음 실행할 때
**“확인되지 않은 개발자”**, **“개발자를 확인할 수 없어 열 수 없습니다”**
같은 메시지가 나타날 수 있습니다.

이 경우:

1. Finder에서 TRPG Organizer를 찾습니다.
2. 앱을 `Control + 클릭` 또는 우클릭합니다.
3. `열기`를 선택합니다.
4. 다시 나타나는 창에서 `열기`를 선택합니다.

또는:

`시스템 설정 → 개인정보 보호 및 보안`

화면 아래쪽에 TRPG Organizer 실행을 허용하는 버튼이 나타나는 경우 해당 버튼을 눌러 주세요.

## macOS 채팅 전송 기능

macOS에서 Roll20 / CCFOLIA 채팅 전송 기능을 사용하려면
TRPG Organizer에 **손쉬운 사용 권한**이 필요할 수 있습니다.

`시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용`

에서 TRPG Organizer를 허용해 주세요.
