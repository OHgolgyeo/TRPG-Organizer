TRPG Organizer 도움말

시작하기

TRPG Organizer는 시나리오와 자료를 정리하고, Roll20 또는 CCFOLIA의 채팅 입력창으로 빠르게 전송할 수 있도록 도와주는 프로그램입니다.

기본 사용법

메인 입력창에 사용할 문장을 작성하거나 불러온 뒤, 필요한 문장을 선택해 복사 모드로 전송할 수 있습니다.

전송 방식은 사용자 도구 메뉴에서 선택할 수 있습니다.

메뉴

상단의 이름을 누르면 나오는 사용자 메뉴,

명령어를 입력해두는 명령어,

스타일 코드를 보관할 수 있는 스타일,

다양한 기능을 설정할 수 있는 환경설정이 있습니다.

편집 모드

메인 입력창의 내용을 직접 작성하고 수정하는 기본 모드입니다.

문장을 추가하거나 삭제하고, 서식을 적용하거나 내용을 정리할 때 사용합니다.

하단의 다중 선택 버튼을 활성화하면 떨어져 있는 단어나 문장의 일부를 여러 곳 선택할 수 있습니다.

복사 모드

복사 모드에서는 입력창에서 문장을 선택하면 선택한 내용을 지정된 채팅 입력창으로 전송합니다.

전송 시 엔터까지 누르기가 켜져 있으면 문장을 입력한 뒤 Enter 키를 눌러 바로 전송합니다.

이 옵션을 끄면 문장만 채팅 입력창에 입력하고 실제 전송은 하지 않습니다.

파일 저장

북마크, 포스트잇, 코멘트, 스타일, 명령어를 포함한 문서를 저장합니다.

불러오면 적용했던 옵션들이 그대로 불러져옵니다.

설정 저장

서브뷰 주소, 스타일, 명령어를 저장할 수 있습니다.

백업을 생활화합시다.

자동 탐색 모드

현재 열려 있는 Roll20 또는 CCFOLIA 창에서 채팅 입력창을 자동으로 찾아 전송합니다.

별도의 채팅 위치 설정은 필요하지 않습니다.

처음 전송할 때는 채팅 입력창을 찾느라 약간의 시간이 걸릴 수 있으며, 한 번 찾은 뒤에는 같은 창을 기억해 이후 전송 속도가 빨라집니다.

채팅창의 크기나 너비가 바뀌어도 입력창을 다시 자동으로 찾아 사용합니다.

직접 지정 모드

자동 탐색이 어려운 프로그램이나 사이트에서 사용할 수 있습니다.

직접 지정 모드를 선택한 뒤 안내창에서 확인을 누르고, 사용할 채팅 입력칸을 직접 클릭하세요.

프로그램이 클릭한 창과 위치를 기억합니다.

이후에는 해당 위치로 문장을 전송합니다.

직접 지정한 창의 위치나 채팅 입력칸 위치가 크게 바뀌었다면 다시 직접 지정 모드를 선택해 위치를 새로 지정해 주세요.

전송이 되지 않을 때

자동 탐색 모드에서 전송되지 않는다면 먼저 대상 사이트의 채팅 화면이 정상적으로 열려 있는지 확인해 주세요.

다른 창이나 메뉴, 설정창 등이 채팅 입력창을 가리고 있으면 자동 탐색이 실패할 수 있습니다.

문제가 계속된다면 직접 지정 모드를 사용해 채팅 입력칸을 직접 지정해 주세요.

자동 탐색 동작 확인 환경

현재 자동 탐색 동작을 확인한 환경은 다음과 같습니다.

  • Roll20
  • CCFOLIA

그 외 사이트나 프로그램에서도 Windows에서 입력창을 인식할 수 있다면 자동 탐색 기능이 동작할 수 있습니다.

명령어

자주 사용하는 Roll20 명령어를 빠르게 삽입할 수 있는 기능입니다.

반복해서 사용하는 명령어를 매번 직접 입력하지 않고 선택해서 사용할 수 있습니다.

좌측 명령어 영역에서 우클릭하면 명령어를 적용할 수 있습니다.

Ctrl + 클릭, Ctrl + Shift + 클릭을 이용해 적용할 영역을 선택할 수도 있습니다.

스타일

Roll20에 적용 가능한 텍스트 스타일 코드를 저장하고 사용할 수 있습니다.

저장한 스타일은 프로그램을 종료해도 유지됩니다.

글자를 선택한 뒤 우클릭하면 저장된 스타일 목록을 볼 수 있으며, 하단에 표시되는 스타일 버튼으로도 적용할 수 있습니다.

다중 선택으로 특정 글자에 일괄 적용을 할 수 있고, 스타일이 적용된 글자는 하이라이트로 구분됩니다.

검색 및 바꾸기

현재 문서 안에서 원하는 단어나 문장을 찾을 수 있습니다.

검색 조건을 이용하면 필요한 부분을 더 빠르게 찾을 수 있으며, 검색한 내용을 다른 단어나 문장으로 바꿀 수도 있습니다.

반복해서 등장하는 표현을 한꺼번에 수정할 때 유용합니다.

기본 검색에서는 포스트잇과 코멘트 내용이 제외됩니다.

필요한 경우 검색 메뉴에서 포스트잇 포함, 코멘트 포함을 선택해 함께 검색할 수 있습니다.

환경설정

프로그램의 디자인과 추가 기능을 설정할 수 있습니다.

색상 테마

프로그램의 전체 색상 테마를 변경합니다.

글꼴

메인 화면에서 사용할 표시 글꼴을 설정합니다.

스타일 뷰어

현재 적용된 Roll20 스타일이 실제로 어떻게 표시되는지 미리 확인할 수 있습니다.

서브뷰

메인 편집창 옆에 보조 패널을 열어 다른 기능을 함께 사용할 수 있습니다.

자주 사용하는 인터넷 주소를 모바일 화면 형태로 확인할 수 있으며, 최대 2개의 서브뷰를 동시에 열 수 있습니다.

간단하게 사용할 수 있는 메모장을 지원합니다.

메모

간단한 내용을 별도로 기록할 수 있는 서브뷰입니다.

메인 화면과 분리된 공간에서 참고 내용이나 임시 문장을 작성할 수 있습니다.

편의성 도구

문서 작성과 정리를 돕기 위한 보조 기능입니다.

편의성 도구에 작성된 내용은 복사 모드로 채팅에 전송되지 않습니다.

포스트잇

문장에 별도의 메모를 붙일 수 있습니다.

포스트잇이 연결된 문장 끝에 표시되는 버튼을 누르면 내용을 확인하거나 수정할 수 있습니다.

코멘트

문장 바로 아래에 보충 설명이나 메모를 입력할 수 있습니다.

코멘트는 필요에 따라 접거나 펼칠 수 있습니다.

북마크

문서에서 다시 확인하고 싶은 위치를 기억할 수 있습니다.

북마크 목록은 프로그램 이름을 눌렀을 때 열리는 메뉴에서 파일 → 북마크 목록으로 확인할 수 있습니다.
